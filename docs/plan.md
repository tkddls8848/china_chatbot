# 중국·홍콩 증시 정보봇 — 뉴스 기반 상승/하락 뷰 벤치마킹 & 수행 계획

## 1. 프로젝트 목표

단순 정보 릴레이(속보 중계)를 넘어서, 중국 본토(선전·상해 메인보드·과창판·창업판)와
홍콩 증시의 뉴스를 받아 **"정제된 나의 시장 뷰에 기반한 상승/하락 판단"**을 내보내는
텔레그램 봇을 지향한다.

핵심 차별점: 정보 공급이 아니라 **정보 정제**. 봇의 출력은 단정적 "예측"이 아니라
**근거 + 확신도(confidence)**로 표현한다.

## 2. 현재 구현 범위 (린 코어)

복잡성을 줄이기 위해 텔레그램 프론트가 실제로 노출하는 기능만 백엔드에 남겼다.
아래가 **지금 동작하는 전부**이며, 뷰 정제(상승/하락 판단)는 이 위에 얹을 향후 과제다.

| 계층 | 현재 구현 |
|---|---|
| 수집 | AkShare 다중 소스 전역 속보(futu·em·sina·ths·cls·RSS) + 소스 자동 페일오버, 관심종목 최근 7일 뉴스 |
| 번역·감성 | Ollama 한국어 번역 + **뉴스별 감성(-1~1)·영향도** 추출, 관련 종목 코드 추출, 부정 뉴스 ⚠️ 경고 |
| 종목 DB | AkShare + HKEX Northbound 가능목록으로 코드·이름·시장 캐시(`/stockdb build`) |
| 관심종목 | `/add` `/list` `/menu` 로 CRUD |
| 운영 | `/system` GPU 오프로딩 제어 + 뉴스 소스 상태, `ALLOWED_CHAT_IDS` 접근 제어, 중복 전송 방지 |
| 감성 뷰(§5 1단계) | 전송 뉴스의 감성 신호를 `data/prediction_log.jsonl`에 축적, `/view` 종목별 참고 뷰, 오프라인 채점 스크립트 |

> 의도적으로 제거한 것(복잡성 축소): LLM 워치리스트 큐레이션(`/research`), 모닝/마감 브리핑·주간 성적표(`/briefing`),
> 정량 컨텍스트(시세·자금흐름·섹터·용호방 스냅샷), EODHD 시총·업종 보강. 아래 벤치마킹은 **이 린 코어를 토대로**
> 필요한 계층만 다시 얹는 방향으로 진행한다(봇 본체를 다시 무겁게 만들지 않는다).

## 3. 목표 아키텍처 (뷰 정제 확장 시)

린 코어(수집 → 번역·감성)에 분석·정제 계층을 **느슨하게 결합**해 독립 교체 가능하게 얹는다.

```
[수집층]   AkShare 뉴스(+선택적 시세)         ← 현재 구현
   │
[감성층]   중국어 FinBERT / FinGPT             ← 현재는 Ollama 프롬프트 감성으로 대체 중
   │       (호재·악재 분류 / 맥락 요약)
   │
[정제층]   TradingAgents식 강세·약세 토론      ← 향후 (별도 프로세스/서비스)
   │       + 나의 시장 뷰 주입
   │
[전달층]   Telegram 봇 (근거 + 확신도 출력)    ← 현재 구현(전송 파이프라인)
```

설계 원칙: 정제층은 봇 본체에 인라인하지 않고 **별도 파이프라인/서비스**로 두어, 실패해도 뉴스 스트림은 계속 돌게 한다.

## 4. 층별 벤치마킹 후보

### 4-1. 데이터 수집층 (중국·홍콩 특화)

| 라이브러리 | 특징 | 역할 |
|---|---|---|
| **AKShare** | 토큰 불필요·완전 무료·호출 제한 없음. 창업판·과창판·북증·홍콩까지 커버 | **주 소스 (현재 사용 중)** |
| Tushare Pro | 토큰 필요·포인트 소모·유료. 재무·기본면 품질 우수 | 선택적 확장 (향후) |
| openbb-hka | OpenBB Workspace 위 AKShare 연동, A주/홍콩 대시보드 + AI 에이전트 | 통합 사례 참고 |

> 주의: AKShare 홍콩 실시간은 신라(新浪) 소스 기준 약 15분 지연.

### 4-2. 감성/뉴스 분석층

| 모델 | 특징 | 역할 |
|---|---|---|
| 현재: **Ollama 프롬프트 감성** | 번역과 같은 호출에서 감성(-1~1)·영향도 추출. 추가 비용 없음 | 현재 구현된 기준선 |
| **중국어 FinBERT** | 중국 금융 뉴스 특화. 감성 분류 정확도 최대 94.5% 보고 | 감성 라벨링 정확도 벤치마크 대상 |
| **FinGPT** (AI4Finance) | LoRA 파인튜닝, 단일 GPU 학습·추론 가능 | 맥락 이해·요약 대안 |
| CFGPT (中文金融) | 중국어 금융 특화 LLM | 감성·요약 백본 비교군 |

> ⚠️ **지표 구분 주의(가장 흔한 함정).** 위 "94.5%"는 *감성 라벨(호재/악재/중립) 분류* 정확도이지 *등락 방향* 적중률이 아니다.
> 뉴스 단독으로 가격 방향을 맞추는 정확도는 현실적으로 훨씬 낮다 — FinBERT 기준 3일 방향 적중률 약 72%(Refinitiv 96만 건),
> 일반적으로 55~72% 대역이다. "FinBERT-LSTM 95.5%" 류의 고수치는 대부분 **가격·기술지표(LSTM) 기여분**이며 뉴스 감성 단독 성능이 아니다.
> → §6 KPI의 목표치는 이 현실 대역과 base rate(§5·§6)를 기준으로 잡는다.

### 4-3. 뷰 정제층 (핵심 차별화 지점, 향후)

| 프로젝트 | 특징 | 역할 |

| **TradingAgents** (TauricResearch, arXiv 2412.20138) | 기본면/감성/기술 분석가 + 강세·약세 리서처 토론 + 리스크팀. LangGraph. DeepSeek·Qwen·GLM 등 지원 | **최우선 벤치마크 / 두뇌 이식** |

| FinRobot / FinMem | 금융 AI 에이전트 플랫폼 / 계층적 메모리 트레이딩 에이전트 | 메모리·뷰 누적 설계 참고 |

### 4-4. 벤치마크용 라벨 데이터셋 (골든셋 부트스트랩)

방향 적중률을 "공개 베이스라인 대비"로 검증하려면 뉴스+가격이 **정렬·라벨링된** 데이터셋이 필요하다.
golden set을 처음부터 만드는 대신, 아래를 초기 벤치마크 셋으로 활용해 우리 파이프라인 수치가 학계 대비 어디쯤인지 먼저 파악한다.

| 데이터셋 | 시장 | 용도 |
|---|---|---|
| **CMIN-CN** | 중국 A주 | 뉴스+가격 정렬, 방향 예측 벤치마크. 중국시장 직접 비교군 |
| **CSMD** (arXiv 2511.01318) | 중국 | 큐레이션된 멀티모달(뉴스·공시·시세) 중국 주식 분석 셋 |
| ESAN 연구리포트 셋 | 중국 A주 | 애널리스트 리포트 55만 건 감성 라벨. 리포트 기반 신호 참고 |
| EDT / "Trade the Event" (ACL 2021) | 미국 | 기업 이벤트 탐지 + 이벤트기반 트레이딩 **평가 프로토콜**(발행시각 기준) 참고 |
| FNSPID (2024) | 미국 | 대규모 뉴스+가격 정렬 셋. 파이프라인·시간정렬 방법론 참고 |
| PIXIU / FLARE | 다국적 | 금융 LLM **평가 하네스**(감성·QA 등 표준화). 모델 교체 시 회귀 테스트 틀 |

> EDT·FNSPID·PIXIU는 미국/영어 중심이라 방향 수치 자체보다 **시간정렬·평가 프로토콜·회귀 테스트 틀**을 빌려온다.
> 중국시장 절대 수치 비교는 CMIN-CN·CSMD 기준으로 한다.

## 5. 수행 계획 (단계별)

### 0단계 — 린 코어 안정화 (완료/유지)
- 뉴스 수집·페일오버·번역·감성 표기·관심종목·종목 DB가 현재 동작 범위. 여기서 시작한다.

### 1단계 — 예측 기록·채점 미니 루프 (즉시, 이번에 구현)

"큰 변경 없이 방향성만 잡는다"는 제약에 맞춘 최소 확장. 신규 의존성 0, 봇 구조 변경 없음.

- **A. 신호 기록** — 전송 뉴스의 감성·관련종목을 `data/prediction_log.jsonl`에 append (`app/state/prediction_log.py`, 약 100줄)
- **B. `/view` 명령** — 최근 `VIEW_LOOKBACK_DAYS`일 감성 집계로 종목별 상승/중립/하락 참고 뷰 + 근거 뉴스 표시. **규칙 기반, LLM 추가 호출 없음**
- **C. 오프라인 채점** — `scripts/score_predictions.py`: AkShare 일봉으로 신호의 N일 방향 적중률을 base rate와 함께 리포트. 봇 런타임과 완전 분리
- 4단계 통제 중 ①(발행 이후 가격만 사용)·②(base rate 병기)를 채점 스크립트에서 즉시 적용. 장중 뉴스가 당일 종가에 일부 반영되는 잔여 누수는 v1 한계로 명시
- **완료 기준:** 신호가 축적되고 적중률 리포트가 나온다 — 이 수치가 이후 단계 착수 여부의 근거

### 2단계 — 평가 하네스 확장 + 감성 모델 벤치마크 (1단계 데이터 확보 후)

기존 계획의 순서 교정: **채점 기준(하네스)이 먼저**고 모델 비교가 그 다음이다.

- 1단계 채점 스크립트를 §6 지표(macro-F1·MCC·Brier)로 확장하고 §4-4 공개 데이터셋(CMIN-CN 등)에도 적용해 학계 수치와 비교
- 현재 Ollama 프롬프트 감성 vs 중국어 FinBERT vs FinGPT 비교(라벨 일치도·속도·비용). 단, `transformers`/`torch` 신규 의존성은 **별도 실험 환경**에서만 — 봇 본체를 무겁게 만들지 않는다
- **나만의 정답셋(golden set) 구축** — 소량이라도 직접 라벨링해 "나의 시장 뷰"와 모델 판단의 괴리를 측정
- **완료 기준:** 감성 백본 교체 여부를 데이터로 결정

### 3단계 — 뷰 정제 엔진 이식 (보류)

TradingAgents 이식은 LangGraph·외부 LLM API 의존이 커서 "작은 변경" 제약과 맞지 않는다.
**1~2단계 적중률이 base rate를 유의미하게 상회하는 것을 확인한 뒤에만 착수를 판단**한다.

- 착수 시: TradingAgents 포크, 백본 LLM을 DeepSeek/Qwen으로 교체(중국 뉴스 이해 유리)
- Bull/Bear 토론 프롬프트에 **나의 투자 원칙·편향·리스크 성향을 시스템 프롬프트로 각인**
- 봇 본체와 분리된 파이프라인으로 두고, 결과만 전달층으로 넘긴다
- **완료 기준:** 뉴스 입력 → 근거 + 확신도 포함한 뷰 출력

### 4단계 — 백테스트 검증 (지속)
- 누적 수익률 / 샤프 지수 / 최대 낙폭(MDD) + **방향성 적중률**을 KPI로 측정
- **평가 방법론(무효한 결과를 막는 통제 4가지):**
  1. **Look-ahead / point-in-time 정합** — 예측은 뉴스 *발행 시각 이후*의 가격만으로 채점한다. 미래 정보가 새면 적중률이 허위로 부풀려진다(§4-4 EDT 프로토콜 차용).
  2. **Base rate 대비 우위** — A주는 상승일 비중이 ~52~55%라, "항상 상승"만으로도 그 정도는 맞는다. 적중률은 반드시 이 다수클래스 base rate 초과분으로 본다.
  3. **다중 베이스라인** — ① 랜덤 ② 항상-상승(base rate) ③ 감성 임계값 규칙 ④ 가격 전용(ARIMA/naïve) 을 모두 두고, 뉴스·뷰 정제가 **가격 전용 대비** 얼마나 더 맞추는지(증분)를 본다.
  4. **뉴스 단독 vs 뉴스+가격 분리** — 고수치는 가격 기여일 수 있으므로, 뉴스만/가격만/결합 세 조건을 각각 측정해 뉴스의 순수 기여를 격리한다.
- 라벨(상승/중립/하락)이 불균형하므로 정확도 외에 **macro-F1·MCC·AUC**를 병기하고, 확신도는 **Brier score / 신뢰도 곡선**으로 캘리브레이션 점검(어긋나면 isotonic 보정)
- 워크포워드(walk-forward)로만 검증하고 전체기간 인샘플 튜닝 금지(과최적화 방지)
- **완료 기준:** 방향성 적중률이 **base rate와 가격 전용 베이스라인 둘 다**를 워크포워드에서 유의미하게 상회, 확신도가 대체로 캘리브레이션됨

### 5단계 — Telegram 전달 계층
- 1단계 `/view`가 이 계층의 미니 구현이다. 정제층 도입 시 근거+확신도 포맷으로 확장
- 판단 결과를 **근거(어떤 뉴스가 어느 방향으로 기여) + 확신도**와 함께 요약 출력
- **완료 기준:** 실사용 가능한 알림 포맷 완성

## 6. 핵심 KPI

| 지표 | 설명 |
|---|---|
| 방향성 적중률 | 상승/하락 방향을 맞춘 비율 (핵심). **base rate 초과분**으로 해석 |
| macro-F1 / MCC | 클래스 불균형(상승/중립/하락)에 강건한 방향 지표 |
| Brier / 캘리브레이션 | 확신도(confidence)가 실제 적중 확률과 일치하는지 |
| 누적 수익률 | 가상 포트폴리오 기준 (거래비용·슬리피지 반영) |
| 샤프 지수 | 위험 조정 수익 |
| 최대 낙폭 (MDD) | 하방 리스크 |
| 뷰 정합도 | 봇 판단 vs 나의 golden set 일치도 |

> 방향성 적중률의 목표치는 절대값이 아니라 **base rate·가격 전용 베이스라인 대비 초과분**으로 정의한다(§5). 뉴스 단독 방향 적중은 현실적으로 55~72% 대역임을 전제로 한다.

## 7. 반드시 짚을 리스크

뉴스 기반 상승/하락 예측은 **본질적으로 확률적이고 자주 틀린다.** TradingAgents 저자들도 백본 모델·온도·기간·데이터
품질에 따라 성과가 크게 달라지며 투자 조언이 아닌 연구 목적임을 명시한다.

→ 따라서 봇 출력은 단정적 "예측"이 아니라 **"근거를 갖춘 뷰 + 확신도"**로 설계한다. 이는 "정제된 나의 시장 뷰"라는
컨셉과 정확히 일치하며, 정제층이 실패해도 린 코어(뉴스 스트림)는 독립적으로 계속 동작한다.
